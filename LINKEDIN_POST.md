# Material para postar no LinkedIn

Este arquivo reúne uma estrutura pronta para divulgar o projeto no LinkedIn de forma mais profissional, objetiva e fácil de copiar.

## 1. Versão pronta para postar

Texto sugerido:

Hoje finalizei um projeto de front-end inspirado na landing page do Disney+.

Neste projeto trabalhei com HTML, Sass, JavaScript e Gulp para organizar os estilos, criar interações na interface e automatizar o processo de build.

Implementei uma estrutura com estilos modulares em Sass, alternância de abas na seção de conteúdos, FAQ com accordion, comportamento dinâmico do header no scroll e geração de assets otimizados em `dist`.

Além da interface, também organizei o fluxo de desenvolvimento para compilar CSS, minificar JavaScript e otimizar imagens com Gulp.

Foi um projeto importante para reforçar prática com:

- estruturação de código front-end;
- componentização de estilos com Sass;
- manipulação do DOM com JavaScript puro;
- automação de tarefas no processo de build.

Repositório do projeto:
https://github.com/PauloHenrique993940/clone_disneyplus-main

Feedbacks são bem-vindos.

## 5. Ordem ideal do que mostrar no post

Se for publicar com vídeo ou carrossel, a sequência mais eficiente é:

1. tela inicial do projeto;
2. seção de planos;
3. troca de abas na área de shows;
4. FAQ abrindo e fechando;
5. pequeno trecho do código Sass ou JavaScript;
6. terminal rodando `npm run dev` ou `npm run build`;
7. tela final com o link do GitHub.

## 8. Checklist antes de publicar

Antes de postar, vale conferir:

1. se o repositório está público;
2. se o README está atualizado;
3. se o vídeo ou prints mostram o projeto com boa resolução;
4. se o link do GitHub foi colocado corretamente no post;
5. se a primeira linha do texto chama atenção rápido;
6. se as hashtags não estão em excesso.

## 9. Melhor formato para LinkedIn

Para este projeto, a melhor combinação costuma ser:

- 1 vídeo curto de 20 a 40 segundos mostrando a interface;
- 1 legenda objetiva com tecnologias e aprendizados;
- 1 link do GitHub;
- 5 a 8 hashtags.

Se não quiser gravar vídeo, publique com 3 a 5 imagens:

- home do projeto;
- seção de planos;
- FAQ;
- trecho do código;
- print do repositório.
